---
description: "Re-queue a failed webhook delivery for immediate retry; the retry counts toward the subscription's max_retries."
openapi: 'openapi-v2-webhooks post /webhooks/{webhook_id}/webhook_deliveries/{id}/retry_delivery'
---

Re-queues a failed delivery for immediate retry. The delivery's `status` is reset to `pending`; `attempts` keeps the attempts already made, so a manual retry counts toward the subscription's `max_retries`. 

 Returns `422` if the subscription's `max_retries` limit has already been reached.
