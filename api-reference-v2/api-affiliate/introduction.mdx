title: 'Introduction'
description: 'This is the Affiliates public API documentation for FirstPromoter V2.'
---

The Affiliate API gives you, as an affiliate, programmatic access to your own data in a FirstPromoter affiliate program: referrals, commissions, payouts, referral links, promo codes, campaigns and reports. It exposes the same data you see in your affiliate dashboard.

Every affiliate can use it. Create a personal API key in your affiliate dashboard under **Profile** → **API & AI tools**; see [Authentication](/api-reference-v2/api-affiliate/authentication).

- **Base URL:** `https://api.firstpromoter.com/api/v2/affiliate`
- **Scope:** each key reads and changes only your own data, in the one program it was created in.

<Tip>
  Want to ask an AI assistant about your earnings instead of writing code? Use the same API key with the [Affiliate MCP server](/mcp/affiliate).
</Tip>
