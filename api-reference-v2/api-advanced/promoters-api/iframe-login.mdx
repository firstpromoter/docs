---
title: 'Generate embedded dashboard token (iframe login)'
description: "Get a short-lived token that signs a promoter in to the promoter dashboard embedded in your app."
openapi: 'openapi-v2-promoters-iframe POST /promoters/iframe_login'
---

Issues a short-lived bearer token for a specific promoter, for use as the `tk` query parameter when embedding the promoter dashboard in an iframe.
See the [embed & auto-login guide](/advanced/embed-dashboard-login) for the full walkthrough.
