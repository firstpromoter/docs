<Warning>
  The FirstPromoter Affiliate MCP server is experimental. Tool names and parameters may change without notice.
</Warning>

The Affiliate MCP server lets you, as an affiliate, ask an AI assistant about your own performance in a FirstPromoter program: referrals, commissions, payouts, links, promo codes, sub-affiliates, postbacks and reports. It is available to every affiliate.

<Note>
  This page is for **affiliates**. If you run an affiliate program, use the [MCP server for program admins](/mcp/overview) instead. It connects with OAuth and covers the whole program.
</Note>

## Example prompts

- "How much have I earned this month, and how much is still pending?"
- "List my referrals from the last 30 days that became customers."
- "When is my next payout and how much will it be?"
- "List my referral links and the campaign each one belongs to."
- "Compare my clicks, referrals and earnings over the last three months, by month."
- "Is jane@example.com one of my customers? Did she upgrade, and what did I earn from her?"
- "Why is there a negative commission on my account?"
- "Is Alex one of my sub-affiliates?"
- "Why didn't my postback fire for my last referral?"

## What it can do

- **Read-only.** The tools only read data. They cannot create, change or delete anything, and they cannot move money.
- **Your data only.** Every answer is scoped to your own affiliate account in one program, the same data you see in your affiliate dashboard.
- **One program per key.** The server uses the API key from the program you created it in. If you promote several programs, add one server entry per program, each with that program's key.

## Connection details

| | |
|---|---|
| **URL** | `https://mcp.firstpromoter.com/affiliate` |
| **Transport** | Streamable HTTP (stateless) |
| **Authentication** | `Authorization: Bearer {your_api_key}` header |

Get the API key in your affiliate dashboard under **Profile** → **API & AI tools**; see [Authentication](/api-reference-v2/api-affiliate/authentication#get-your-api-key). The key already identifies the program, so the MCP server does not need an Account ID.

<Note>
  The affiliate server authenticates with an API key header, so it works with MCP clients that let you set custom headers. Connectors that only support OAuth (such as custom connectors on Claude web or ChatGPT) cannot connect to it yet.
</Note>

## Connect

### Claude Code (CLI)

```bash
claude mcp add --transport http firstpromoter-affiliate https://mcp.firstpromoter.com/affiliate \
  --header "Authorization: Bearer {your_api_key}"
```

Run `/mcp` inside a session to verify the connection and browse the available tools.

### Cursor

Add the server to `~/.cursor/mcp.json` (or `.cursor/mcp.json` in a project):

```json
{
  "mcpServers": {
    "firstpromoter-affiliate": {
      "url": "https://mcp.firstpromoter.com/affiliate",
      "headers": {
        "Authorization": "Bearer {your_api_key}"
      }
    }
  }
}
```

Other MCP clients that support streamable HTTP with custom headers use the same URL and `Authorization` header.

### Claude Desktop

Claude Desktop's configuration file starts local servers, so use the [`mcp-remote`](https://www.npmjs.com/package/mcp-remote) bridge (requires Node.js). Open **Settings** → **Developer** → **Edit Config** and add:

```json
{
  "mcpServers": {
    "firstpromoter-affiliate": {
      "command": "npx",
      "args": [
        "-y",
        "mcp-remote",
        "https://mcp.firstpromoter.com/affiliate",
        "--header",
        "Authorization:${AUTH_HEADER}"
      ],
      "env": {
        "AUTH_HEADER": "Bearer {your_api_key}"
      }
    }
  }
}
```

Restart Claude Desktop after saving the file.

### Several programs

Add one entry per program, each with its own key, for example `firstpromoter-acme` and `firstpromoter-globex`. The assistant then sees each program as a separate set of tools.

## Available tools

| Tool | Description |
|---|---|
| `get_me` | Your affiliate profile in the program: name, email, balances and the campaigns you belong to. |
| `list_campaigns` | Campaigns you are part of. Takes only `page` and `per_page`. |
| `list_referrals` | Your referrals. Filter by `type`, `state`, `campaign_id` and a `created_from` / `created_to` date range. |
| `find_referral` | Checks whether a customer or lead is one of your referrals, by their exact `email` or `uid`. Returns the matching referral, or nothing when it is not yours. Looking up by email is not available while the program hides referral emails. |
| `list_commissions` | Your commissions. Filter by `status`, `paid`, `campaign_id`, `referral_id` (the commissions of one referral, for example its upgrades and refunds) and a `created_from` / `created_to` date range. |
| `list_payouts` | Your payouts. Filter by `status` and `campaign_id`. |
| `get_payout_stats` | Amounts of your next and overdue payouts with their period and payment dates, pending payouts without a set period, and the program's payout terms. Takes no arguments. |
| `list_referral_links` | Your referral links, optionally for one `promoter_campaign_id`. |
| `list_promo_codes` | Promo codes assigned to you, optionally for one `promoter_campaign_id`. |
| `get_performance_report` | Clicks, referrals, customers and earnings between `start_date` and `end_date` (default: the last 30 days), grouped by `group_by` (`day`, `week`, `month` or `year`; default `day`), optionally for one `campaign_id`. |
| `list_sub_affiliates` | Affiliates you referred to the program (your sub-affiliates), top sellers first. Names and emails are masked when the program masks sub-affiliate details. |
| `list_postbacks` | Your postbacks: the URL, campaign and event each one sends. Postbacks are added and changed in your affiliate dashboard. |
| `list_postback_events` | The deliveries of one postback (`postback_id`, required), newest first: status, tries, the error your URL answered with, and the referral or commission that triggered it. |

Tools follow the program's settings for your dashboard: a column the program hides from you cannot be used as a filter or lookup, and the tool returns an error instead.

Every `list_*` tool, including `list_campaigns` and `list_referral_links`, is paginated with `page` (default 1) and `per_page` (default 20, maximum 50) and returns `page`, `per_page`, `total_count` and `total_pages` in its `meta`. The tools return the same fields as the [Affiliate API](/api-reference-v2/api-affiliate/introduction).

## Errors

- **401 Unauthorized**: the `Authorization` header is missing, or the key is wrong, regenerated or disabled.
- **403 Forbidden**: the token is not an affiliate API key (for example a dashboard session or a program admin's token), your affiliate account is archived, or your email is not confirmed yet.
- A tool can also return an error with the same message the dashboard shows, for example when you still need to add a payout method before you can see your data.

## Security

- The MCP server is read-only, but the key behind it is not: anyone who has it can read your data in the program and change it through the [Affiliate API](/api-reference-v2/api-affiliate/authentication#security-best-practices). Do not share it or commit it to a repository.
- If a key is exposed, **regenerate** it in **Profile** → **API & AI tools**. The old key stops working for both the API and the MCP server, so update your MCP configuration with the new key.
- **Disable** API access to cut off every connected AI tool at once.
