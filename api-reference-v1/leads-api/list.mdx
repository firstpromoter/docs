---
title: 'List leads/customers'
description: "List leads and customers for a promotion, promoter, campaign or the whole account, with pagination in the response headers (legacy v1 API)."
openapi: 'openapi-leads GET /list'
---

With this endpoint you can list all the leads and customers assigned to a promotion, promoter, campaign or entire account using the API. <Note>Pagination details are held on response headers. Add `--include` option on `curl` request to see the pagination details format and links to next pages.</Note>
