---
title: 'Create new reward'
description: "Create a reward or commission for the promoter who referred a lead, found by lead_id, email or uid (legacy v1 API)."
openapi: 'openapi-rewards POST /create'
---

With this endpoint, you can assign a commission generated by a referral, and it will be recorded to the promoter who referred the lead/customer. You can find the referral by lead_id, email, or UID.<br/><br/>If the reward/commission is not generated by a lead/customer, you can assign it directly to a promoter through its promotion. You can find the promotion by `promotion_id` or `ref_id`. <Note>Note: To assign rewards/commission for sales via the API use the Tracking API</Note><Note>If this call is successful and you enabled 'Promoter gets a new commission/reward' emails for the campaign, it will send emails to the promoter. To skip the emails, set the `skip_email_notification` parameter to `true`</Note>
