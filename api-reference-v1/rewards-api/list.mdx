---
title: 'List rewards and commissions'
description: "List rewards and commissions for a promotion, promoter, campaign or the whole account (legacy v1 API)."
openapi: 'openapi-rewards GET /list'
---

With this endpoint you can list all rewards and commissions assigned to a promotion, promoter, campaign or entire account using the API.<Note>Pagination details are held on response headers. Add `--include` option on `curl` request to see the pagination details format and links to next pages.</Note>
