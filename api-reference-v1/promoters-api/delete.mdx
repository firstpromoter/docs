title: 'Delete a promoter'
description: "Delete a promoter identified by id, cust_id, auth_token, email or ref_id (legacy v1 API)."
openapi: 'openapi-promoters DELETE /delete'
---


You can identify promoters by: **id, promoter_email,  cust_id, auth_token or ref_id(referral id)**. You need to pass at least one of these parameters.
