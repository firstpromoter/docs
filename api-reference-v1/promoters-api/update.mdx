---
title: 'Modify existing promoter'
description: "Update a promoter's profile, IDs or payout details, identified by id, email, cust_id, auth_token or ref_id (legacy v1 API)."
openapi: 'openapi-promoters PUT /update'
---

You can identify promoters by: `id`, `email`, `cust_id`, `auth_token` or `ref_id`(referral id). You need to pass at least one of these parameters.
